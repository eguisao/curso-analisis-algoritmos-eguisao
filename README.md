# Curso de Análisis de Algoritmos

Repositorio para el desarrollo de actividades, ejercicios y laboratorios del curso de Análisis de Algoritmos.

## Estructura del repositorio

- `laboratorios/`: contiene los cinco informes de laboratorio evaluativos del curso.
- `ejercicios-clase/`: contiene los ejercicios prácticos desarrollados durante las sesiones de clase.
- `benchmarks/`: contiene los scripts utilizados para medir tiempos de ejecución y generar gráficas.

## Herramientas utilizadas

Durante el curso se utilizarán diferentes herramientas para el desarrollo y análisis de algoritmos:

- Python
- Git
- GitHub
- Visual Studio Code
