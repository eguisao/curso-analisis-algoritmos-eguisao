# laboratorio 02 - Entorno de trabajo

- Para crear el entorno virtual se utilizó el comando `python -m venv venv`.
- En Windows, el entorno se activó con `venv\Scripts\activate`.
- Las dependencias instaladas se guardaron en `requirements.txt`.
- El archivo se generó mediante el comando `pip freeze > requirements.txt`.
- Para reproducir el entorno, primero se debe clonar el repositorio.
- Luego se crea un nuevo entorno virtual con `python -m venv venv`.
- Después se activa con `venv\Scripts\activate` y se ejecuta `pip install -r requirements.txt`.
